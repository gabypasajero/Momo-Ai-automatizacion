# Extensión de Chrome · Momo AI

Una burbuja con la cara de Momo en la esquina superior izquierda de cualquier página (por ejemplo, Marketplace)
muestra tus conversaciones abiertas y quién te espera.

## Instalar

1. Descárgala desde Momo: **Ajustes › Canales › Descargar extensión** (o usa esta carpeta).
2. Descomprime el archivo.
3. En Chrome abre `chrome://extensions`, activa **Modo desarrollador** y elige **Cargar descomprimida**.
4. Selecciona la carpeta `momo-extension` e inicia sesión con tu correo y contraseña de Momo (ícono de Momo en la barra).

## Uso

- **Burbuja**: clic para abrir o cerrar la lista. El número = clientes que te esperan.
- **Chats**: ordenados con los que te esperan primero. Clic para abrir el chat en Momo (reutiliza la pestaña de Momo, nunca abre ventanas de más).
- **Filtros**: por estado de la venta (Consulta, Cotizada, Pagada, Área de Diseño…).
- **Ícono de la barra**: sesión, actualizar, ver quién te espera y ocultar la burbuja.

La lista se actualiza cada minuto. Los datos se leen con tu sesión: solo ves las conversaciones de tu empresa.
